## Účel

Tento pracovní návrh popisuje možné zveřejňování a úpravy dokumentů CCA.
Nejde o schválenou směrnici.

## 1. Zdrojové soubory

**1.1** Dokumenty se spravují v Markdownu. PDF a webové verze jsou automaticky
generované výstupy ze stejného zdroje.

**1.2** Záhlaví dokumentu obsahuje název, verzi, stav, odpovědný tým, datum
aktualizace a u schváleného dokumentu také datum účinnosti.

## 2. Návrhy změn

**2.1** Autor změny otevře pull request s popisem navrhované úpravy.

**2.2** GitHub Actions připraví PDF pro kontrolu. Kontrolující posoudí změnu
textu i výslednou sazbu.

**2.3** Po schválení a sloučení pull requestu se aktualizuje web dokumentace.
Oprávněné schvalující osoby se určí samostatně.

## 3. Verze a účinnost

**3.1** Pracovní návrh se viditelně označí jako návrh. Datum aktualizace
nenahrazuje datum účinnosti.

**3.2** Historie změn je dostupná v GitHubu. Trvalý veřejný archiv starších PDF
vyžaduje samostatné uchování vydaných souborů; tento první návrh jej nezavádí.
